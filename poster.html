01 Abstract
Traditional desktop voice assistants remain fundamentally blind and helpless inside dynamic web interfaces, relying on rigid, pre-programmed intent patterns. Project Elyra introduces an autonomous, multimodal desktop AI assistant that operates web applications and the Windows OS exactly like an expert human. By integrating the bidirectional Google Gemini Multimodal Live API (16 kHz low-latency audio & vision), Chrome DevTools Protocol (CDP port 9222) via Playwright, and a custom C++ Native Addon (`node-addon-api`), Elyra perceives real-time screen state, dynamically indexes interactive elements with high-contrast numbered badges ([1], [2]...), and executes multi-step workflows (autonomous form completion, multi-source deep research, and headless SMTP email dispatch) entirely hands-free.
02 Problem Statement & Key Objectives
  • Brittle Selectors: Conventional RPA frameworks (Selenium/Puppeteer) rely on hardcoded CSS/XPaths that fail on layout shifts.
  • Disjointed AI Agents: Contemporary LLMs produce natural text but lack local agency to execute tasks directly on the host OS.
  • Blind Runaway Loops: Lack of continuous state verification leads to unrecoverable errors when popups or modals appear.
Primary Objectives:
  • Build sub-second, full-duplex WebSocket streaming for 16 kHz PCM voice and delta-diff screen frames.
  • Design a dynamic visual DOM tree-walker eliminating hardcoded selectors via numbered badge injection.
  • Implement an Execution Governor with Human-in-the-Loop gating for headless background emails and OS actions.

05 Core Methodology & Novel Algorithms
  • Dynamic DOM Tagging Protocol: Lightweight tree-walker calculates bounding client rectangles of visible elements and injects high-contrast numbered badges ([1], [2]...). The model acts deterministically on element IDs without xpath fragility.
  • Execution Governor & Human-in-the-Loop Gate: Enforces a strict 1 User Turn = 1 Task Card anchor. Spontaneous action hallucination is suppressed; destructive and email dispatches require explicit voice authorization.
  • Deterministic 4-Pillar Deep Research: Decomposes complex research queries (e.g. MITS Gwalior) across Foundation/Accreditation, Academics, Placements, and Campus Scale, linking live Brave navigation with structured markdown dossier synthesis.
  • Kernel-Level C++ Acceleration: Native Win32 `SendInput` bypasses Windows 11 NumLock flickering and injects large multi-line text into Notepad via clipboard acceleration in under 250 ms.
06 Verified Core Workflows & Execution Pipeline
  • Automated Web Form Completion: Parses open-ended voice prompts, navigates Chromium via CDP, indexes dynamic fields using numbered badges ([1], [2]...), and inputs personal credentials with zero human intervention.
  • Headless Email Dispatch with Human Gate: Drafts structured messages asynchronously via Nodemailer (TLS 465). Traps execution in an interactive card (*"Waiting for user authorization"*) until physical voice confirmation is granted.
  • Multi-Source Deep Research & OS Injection: Concurrently queries and verifies primary institutional domains, synthesizes structured academic dossiers, launches Windows Notepad, and injects text via C++ clipboard acceleration in < 250 ms.
