1 Problem vs. Solution
The Problem: Traditional voice assistants (Siri, Alexa) are blind to desktop screens and cannot navigate websites. Conventional web RPA (Selenium) breaks instantly when site layouts shift.
The Elyra Solution: Combines real-time Gemini Live Vision with Dynamic Numbered DOM Tagging to let AI navigate websites and control Windows OS exactly like an expert human — with autonomous self-healing.
2 How It Works (4-Step Pipeline)
[1] Voice & Screen Perception Captures 16 kHz PCM microphone stream and delta-diff desktop frames in real time.
▼ Full-Duplex WebSocket ▼
[2] Multimodal Cloud Reasoning Google Gemini Live API interprets intent, decomposes multi-step goals, and invokes tools.
▼ Chrome DevTools Protocol (CDP) ▼
[3] Dynamic Numbered DOM Tagging Injects high-contrast numeric badges ([1], [2]...) directly over buttons/inputs, eliminating brittle XPaths.
▼ Native OS & Browser Execution ▼
[4] Execution, Safety Gating & Verbal Output Executes clicks, types, and sends emails with voice confirmation, then speaks status back.
3 Core Architecture & Stack
Modular Electron host connecting a reactive React HUD with Gemini Live via WebSockets, orchestrating Brave Browser via CDP and Windows OS via native C++.
Gemini Live API Electron 30 React 18 Playwright CDP C++ Win32 Core Nodemailer SMTP Better-SQLite3
4 Core Innovations
1. Visual Numbered DOM Tree-Walker: Scans visible elements in <15ms and overlays numeric badges ([1], [2]...). The model acts deterministically without selector fragility.
2. Safety & Anti-Loop Governor: Enforces 1 User Command = Exactly 1 Task Card. Sensitive actions (emails, system commands) require explicit voice confirmation (*"Haan bhej do"*).
3. Kernel C++ Clipboard Acceleration: Injects large multi-line research reports into Notepad in <250 ms via Win32 API, completely eliminating NumLock flickering and dropped keys.
